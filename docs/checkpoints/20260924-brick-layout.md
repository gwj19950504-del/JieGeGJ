## 用户要求及最新澄清

- 孔心排版移到原工具末尾，在其后增加“砖纹排版”。
- 在固定1220×2440mm整板上排砖纹。小砖宽、高、缝隙可修改，**60×240、缝隙5mm仅是测试示例**。
- 参考实物照片灰色水泥材质、直缝砖纹和整板效果；提供尺寸标注，类似参考图的砖尺寸、缝尺寸和板尺寸。

## 实现

- `tools/brick-layout.html`：独立第十个工具，苹果风参数栏及图纸区，固定整板说明、三个数字框、宽高互换、载入示例、复制/PNG/SVG。
- `tools/brick-layout-core.js`：纯几何模块，整数0.1mm计算；净砖尺寸加间隙形成步距，左上起排，末端直接收边，不平均拉伸。支持0缝、余槽、单格覆盖；输入非有限/越界/超精度报错，超过6000格不生成。
- `tools/brick-layout.js`：确定性水泥矿物颗粒、明暗凹槽、整板和局部放大，黑色净尺寸标注；实际槽深未设定，界面有示意说明。SVG内嵌纹理、不依赖外部图片，PNG为2200×2620；复制受限时自动下载。异步导出期间锁定输入，防止图文参数错配。
- `tools/brick-layout.css`：仅新页布局，沿用共享苹果风控件。桌面参数/图纸双栏，小屏参数置上；手机保留图纸可读宽度，仅画布内部横向滚动并提示。
- `index.html`：十个路由；默认最后两项为孔心、砖纹；兼容旧排序，只移动孔心及新增砖纹，保留其余旧相对顺序。仍支持后续手工拖动保存。
- 新文件缓存20260924-1。未更改共享CSS、共享业务核心、孔心/上墙材质或水印、客户价格表。
