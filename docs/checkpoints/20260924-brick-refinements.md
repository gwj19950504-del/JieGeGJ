# 2026-09-24 砖纹材质、复制水印与均分建议

当前主版本 `v2026.09.24.2`。本轮完成，只交付唯一完整源文件夹；未上传、未压缩、未修改5.0、客户价格表或其他子工具业务。下一轮只处理新的明确需求。

## 本轮需求

- 去掉砖纹材质里若隐若现的多余直线，真实砖缝保留。
- 复制此图能直接粘贴图片，带与上墙相同的原版M·M水印。
- 宽和高各提供一个严格小于当前值、一个严格大于当前值的最近均分尺寸，计算计入缝隙，采用后不留裁切格。

## 实现与边界

- `tools/brick-layout-core.js`：公式 `砖面净尺寸=(整板长度−(格数−1)×缝隙)/格数`。尺寸随格数单调递减，直接找输入两侧相邻整数格数；当前恰好均分时跳过自身。有效范围内不存在的一档返回null，不虚构建议。
- 普通输入扩大到6位小数，使用整数百万分之一mm生成分段，避免累计浮点误差。建议显示值也是6位小数；匹配某档的标准六位值时按精确公式绘图，标注≈并说明不是加工取整。97.083333识别为12等分；97.1仍按手工尺寸产生实际收边。不假装整数97或101能在5mm缝下均分1220mm。
- 均分有n个同宽砖面、n−1道内缝，不多画板边缝。宽高各自建议在另一轴无效时仍可用；改缝隙、宽高互换和示例重置同步重算。总格数6000上限保持。
- `tools/brick-layout.js`：旧128mm重复SVG pattern换成610×1220像素的单张连续整板矿物纹理；取消周期噪声取模，消除反复出现的贴图边界。局部图裁剪同一材质。只在真实砖槽位置画槽线。
- `tools/mm-watermark.js`：从上墙内嵌资源机械提取原PNG，SHA256为 `c4020d774ff85f9d9bf509643c22731eae013b3a7f0f823418ff9b677fb233c0`，1933×2522，保留原字形和Alpha。资源在本地，无远程依赖。
- 输出时克隆SVG，原水印等比缩放、居中、0.82透明度，裁剪在主板内部，尺寸和局部放大不盖水印；复制、下载PNG、SVG均带水印。预览DOM不加水印，与上墙交互一致。剪贴板使用ClipboardItem中的PNG Promise保留点击授权；失败明确告知并下载，不假报复制成功。
- CSS缩放限定顶层SVG，避免嵌套SVG材质裁剪被页面响应式宽高覆盖。窄输入框降低到14px并去掉步进器，完整显示六位小数；六档宽度实测。
- 缓存20260924-2；主工具首页版本同步。文档和归档同步，新增资源必须随完整文件夹上传。

## 保留限制

- 只支持对齐直缝、左上起排；未定义错缝、外框、槽深和实际加工公差，不能推定已有。
- 无权限/不支持图片剪贴板的浏览器仍会改为下载，并明确提示；真实粘贴验证范围为本地Chrome。
- 几何均分是精确数学尺寸；显示的循环小数是近似标注，按整数取整不能保证现场无收边。
- 141项回归覆盖整个主工具，但本轮实际浏览器验收只针对砖纹及其首页入口，不声称再次巡检了所有旧页面。
