# 杰哥工具 5.0 开发入口

- 5.0 基线来源：杰哥工具 4.0 最终归档版 `v2026.08.10.3`。
- 当前版本：`v2026.09.05.1`，完成全工具功能与排版巡检，详见 `整体检查报告-20260905.md`。
- 建立日期：2026-08-10。
- 4.0 历史业务规则：见 `杰哥工具4.0-需求归档.md`。
- 当前回归基线：80 项；首页与9个工具完成1440/390像素检查，新增计算、输入边界与手工编辑保护测试。
- 后续所有新功能、价格调整和规则修改只在本目录进行。
- 每次修改应在本文件追加简短记录，避免再次依赖超长 Codex 对话恢复上下文。
