# 杰哥工具 4.0 需求归档

归档日期：2026-08-10  
归档状态：4.0 已封版；后续修改只在“杰哥工具5.0”继续。  
历史 Codex 任务：`019efd9c-a60f-7513-ac1c-11d24fa0b74f`（归档后不再继续追加上下文）。

## 一、长期维护原则

1. 任何涉及同一业务的修改，都必须检查并同步所有相关子工具，不能只改一个页面。
2. 产品价格统一维护在 `tools/product-data.js`；鎏金运费/DB/顺心捷达统一维护在 `tools/freight-gold-core.js`；宁波合装运费统一维护在 `tools/ningbo-freight-core.js`。
3. 页面引用公共脚本时必须更新缓存版本号，避免 GitHub Pages 继续加载旧文件。
4. 不支持或无法识别的规格必须提示人工确认，不能偷偷回退成默认规格。
5. 每次交付必须提供完整 GitHub 包，包含首页、全部 `tools`、公共 JS、图片资源、上传说明和回归测试；不能只发单个 HTML。
6. 每次修改后运行完整回归测试，并实际检查受影响页面；优先修改同一份主版本，避免堆叠多个检查副本。

## 二、工具入口

- 开单模板：浙江仓、宁波仓、混凝土仓、水泥板仓库、自选仓的开单与费用核算。
- 文字报价：单产品/多产品报价、费用、税金、历史记录、鎏金运费提问和顺心捷达自动报价。
- 快速查价：鎏金板、宁波柔岩、混凝土等产品价格与规则说明。
- 报备模板：项目报备内容生成。
- 孔心排版：1200×600 板孔位计算与 SVG 导出。
- 鎏金运费：多规格重量、包装、DB、顺心捷达自动报价。
- 宁波重量：多产品合装重量与木箱尺寸计算。
- 整板切割：小板需求换算整板用量和排版。
- 上墙排版：多墙面、孔位、裁切统计及 SVG/PNG 导出。
- 2026-09-24 新增砖纹排版：导航中孔心排版移到原工具末尾，其后为砖纹排版；既有浏览器保存的排序需迁移，其余工具相对顺序保留。

### 砖纹排版（2026-09-24）

- 整板固定宽1220、高2440mm，不提供修改整板大小。小砖宽、高、横竖同宽缝隙三项可自由调整，60×240mm、5mm缝隙仅用于测试示例，不能锁定为业务规格。
- 参考用户实物照片的灰色水泥质感与凹槽；直缝对齐、左上起排，砖面尺寸不含缝隙。末端不足一格保留实际余量，不拉伸整板或均摊砖纹；板边落在槽中显示实际余槽。
- 图纸包含整板宽高、小砖净宽高、缝隙尺寸及局部放大，标注黑字；复制、PNG和SVG与当前参数一致。材质为效果示意，不虚构槽深、公差和加工参数。
- 宽高正数、缝隙可为0。2026-09-24 v2允许最多6位小数（替代初版0.1mm）。无效参数清除旧图并阻断导出；密集排版超过6000格明确提示，不静默减少格数。
- v2新增：宽、高各提示严格小于/大于输入值的最近均分尺寸，可点击采用。按净尺寸×格数+(格数−1)×缝隙=整板长度，四周无额外边缝；循环小数显示≈及6位小数，计算使用精确均分值，不能四舍五入为整数再宣称无裁切。已经均分仍显示上下相邻档；范围内不存在的档位如实提示。
- v2新增：去掉重复贴图造成的隐约直线，使用整板连续水泥纹理，仅保留真实槽缝。复制应为可粘贴PNG图片；复制/PNG/SVG输出均带与上墙工具相同原PNG水印，保留原字形与Alpha，不能换成系统字体。预览保持清晰无水印，与上墙使用方式一致。
- 该工具独立于孔心/上墙；此次照片配色不修改此前两页的中灰材质和几何。初版“不新增水印”由上述v2用户要求取代。

## 三、浙江仓、鎏金板与 DB

### DB 计费

- 小板（短边不超过 600、长边不超过 1200）：`0.5元/片`。
- 中板（短边不超过 600、长板规格）：`0.75元/片`。
- 大板：`1.5元/片`。
- 混装逐项累计，最终四舍五入为整数，单票封顶 `100元`。
- 开单模板、鎏金运费、文字报价必须共用同一 DB 核心。

### DB 在开单中的位置

- 浙江仓“跨越”和“货拉拉”不代收 DB：DB 写入开单正文并从 KD 中扣除。
- 顺心捷达、姜冉、西武及其它非跨越/非货拉拉物流：DB 放在开单正文下方的运费明细中，不从 KD 扣除。
- 货拉拉开单正文不显示重量公式和包装行，但必须在货物明细后显示 `DB：金额`，并计入 KD 扣减。
- 自提时，完整开单正文仍隐藏重量、包装和 DB；上方核算及下方运费提问仍保留。

### 浙江仓修补剂

- 2026-08-20 起，浙江仓附加工艺提供修补剂 `50g/15元`、`100g/30元`、`200g/50元`、`500g/125元` 四种规格，执行 2026-07-01 价格。
- 四种规格可以任意多选；每项勾选后默认数量为 1，可分别修改数量，同规格支持多份。
- 修补剂必须按“规格×数量”自动计算金额，单独写入开单明细，并从 KD 中扣除；不得合并成无法核对规格的手工加工费。
- 修补剂界面默认折叠，点击标题后才展开；规格与数量同行排列，不显示单项小计，只在折叠标题中显示修补剂合计。
- 折叠标题右侧必须提供明确的“点击展开”按钮，展开后自动变为“点击收起”，避免开单人不知道该区域可操作。
- 修补剂只适用于“浙江仓 + 鎏金板”；切换到砂岩板、其它品类或其它仓库后必须停用且不得继续收费。

## 四、顺心捷达自动报价

1. 三个入口共用 `shunxin-rates.js` 与 `freight-gold-core.js`：鎏金运费、开单模板、文字报价。
2. 开单模板只要是“浙江仓 + 鎏金板”就始终显示顺心捷达窗口，不依赖物流是否勾选顺心捷达。
3. 文字报价始终保留顺心捷达窗口；未填写鎏金产品时显示填写提示，填写后自动计算。
4. 计费重量取实际重量与体积重量的较大值；体积重量公式：`长×宽×高×200`。
5. 2026-08-15 起统一使用嘉兴发全国最新四档报价：`100–500KG`、`500–999KG`、`1000–2000KG`、`2000KG以上`；边界按前一档包含 500KG 和 2000KG、后一档从超过该边界开始，特殊地区转人工询价。
6. 托盘自动报价限制：三边和不超过 `4.8m`、高度不超过 `1.8m`、实际重量不超过 `1000KG`。
7. 保费：货值 `≤2000元` 默认 `5元`；超过 2000 元按货值 `0.003` 计算。开单模板和文字报价自动读取总价；鎏金运费由用户填写货值，未填按 5 元。
8. 上门费：`≤40KG` 免费；超过 40KG 按 `25元 + 0.1元×计费重量`。默认不勾选，但金额始终显示；勾选后才并入运费合计。
9. 顺心捷达报价合计包含基础运费、保费、DB，以及勾选后的上门费，并显示完整计算过程。
10. 最新报价表另列条件费用：到付手续费按到付金额6%且最低5元/票；代收货款按返款周期和金额分档收费；月出货量低于200吨时每公斤加收0.2元。现阶段统一显示为附加条件提示，因订单条件不完整不强制并入普通自动报价。
11. 最新原始报价表归档在 `docs/顺心捷达最新报价表-20260815.xlsx`，所有入口只通过 `tools/shunxin-rates.js` 和 `tools/freight-gold-core.js` 使用该规则，不得在单个页面另写一份费率。
12. 地址匹配必须优先识别地址开头的省级/市级行政区，不能因“上海路”“贵阳路”等道路名误判；同一文本明确出现多个不同省级地区时停止自动报价并提示人工确认。
13. 鎏金板厚度必须严格识别：硬板仅按 `6mm`、软板仅按 `2–3mm` 标准核算；缺少厚度、出现 `20mm` 等非标准厚度或规格无法识别时转人工确认，不能静默套用硬板默认值。
14. `1200×600mm` 小板目前只有包装重量和每托盘数量规则，缺少经确认的托盘长、宽、高；因此重量、包装数量和 DB 可以自动核算，但顺心捷达体积重及最终运费继续提示人工询价，不得虚构尺寸。

- 2026-09-24 另做宁波仓价格表快照：只能从开单共用的 `ningboProductCatalog` 提取，按“产品名＋具体规格”逐行列价，不得将同名产品不同规格合并成一个价。初版为双价及内部说明稿，现只作内部历史记录。
- 2026-09-24 客户版最新要求：主题为“MM苗苗柔岩板价格表”，只展示产品名称、规格、出厂价、备注；出厂价统一为目录价+10元/㎡，备注“打印另加10元/㎡”。不得向客户展示目录底价、计算公式、含打印/3D等开单例外或内部来源说明。客户版单独放在本 GitHub 专用主目录外的 `../宁波仓价格表/客户版/`，网页与Excel一致；生成脚本及专项测试一并在外部。该客户价格口径不反向修改开单自动计价。
- 鎏金、砂岩、宁波产品的规格与价格尽量只保留在公共产品数据中，开单、查价和报价共同读取。
- 2026-08-19 起，宁波仓产品正式名称统一为“20圆柱”，底价 `95元/㎡`、规格 `3000×1200mm`；“30内圆”底价统一为 `90元/㎡`、规格 `3000×1200mm`。开单模板、文字报价、快速查价和宁波重量必须共同读取这套数据，不能保留“20内圆”旧名称或单独价格。
- 2026-09-04 起，宁波仓非洞石产品尺寸以 `docs/柔岩板价格表_最终尺寸替换版.xlsx` 为最新权威来源；本次共确认并同步 22 项尺寸调整。所有名称包含“洞石”的产品继续保留原规格、价格和重量规则，不从该表覆盖。
- “大漠沙丘……珠光白”中的“珠光白”是颜色，仍按大漠沙丘系列计价；单独输入“珠光白”才按珠光系列。
- 快速查价中 8 个鎏金系列同时展示底价和最低售价，最低售价不能改写共享底价。
- 同名产品来自不同仓库时，快速查价必须同时保留结果并标明仓库来源。
- 同名产品存在多个规格和价格时，价格必须绑定到具体规格展示和计算，不能把第一条价格合并给全部规格。
- 混凝土松诺、168 的价格必须由 `tools/product-data.js` 的同一张公共表提供给开单模板和快速查价；用户手工修改单价后必须保留，只有清空时才恢复自动价。
- 2026-09-03 起新增美利来仓；`docs/美利来价格明细表2026.4.13.xlsx` 是美利来产品名称、规格、底价和备注的权威来源。开单模板与快速查价必须读取 `tools/product-data.js` 中同一份完整数据，不能在两个页面分别维护价格。
- 美利来选择产品和具体规格后自动带出表格底价；原表红字备注必须在该产品规格下方显示醒目小字，普通备注也需要展示。不在价格表中的规格或价格不得自行推测，保留人工填写并提示核对。
- 美利来最多支持 5 个产品，价格选项只保留“打印 +10元/㎡”；物流只保留“默认”和“自提”，付款方式与渠道沿用宁波仓，不生成物流询价模板。

- 美利来支持勾选后新增多条自定义费用，每条可填写费用名称与金额，例如加工费或包装费；费用需要逐条写入开单正文并从 KD 中扣除。
- 美利来开单品类固定写“柔岩板”，不能把仓库名称“美利来”误当作品类。美利来与宁波仓互相切换时必须清空上一仓的产品、规格、数量、价格和附加选项，输入框提示也要随仓库切换，避免跨仓误开。
- 美利来自动包装费规则只需通过输入框名称与自动金额体现，不在输入框下重复占用一行说明；加工费、包装费、税金和自动税金应在桌面端同行对齐，单片价格不得增加额外套框导致高度不一致。
- 美利来包装费默认按规格和片数自动生成并锁定；“自动包装费”旁提供“手动填写”勾选项，勾选后由开单人填写金额并以该金额写入正文、扣入 KD。取消勾选、切仓或重置下一单时恢复自动规则。
- “手动填写”必须紧跟“自动包装费”标题同行显示，不能用两端对齐把开关推到税金栏附近；桌面端四个费用区保持整齐同行，手机端自动改为单列。

## 六、宁波重量与运费

- 2026-09-20 起，仅宁波仓的完整开单信息在第一行重复物流及付款信息，例如“明邦，到付”，正文原有运费和送货内容不删除。首行复用当前运费内容并保留手填金额，例如“明邦，100代付”；默认物流不虚构承运商，自提显示“工厂自提”。预览与复制一致，不改变其他仓（包括美利来）、独立运费询价模板或金额/KD计算。手工编辑后的完整正文继续原样复制，恢复自动生成后重新生成首行。
- 宁波重量工具支持加入多个不同产品/规格，同票尽量合装一个木箱。
- 木箱宽、长分别取所有产品最大值后各加 `100mm`。
- 木箱高度按各产品厚度×数量累计，再加 `200mm`。
- 合装只计算一次包装重量，总重量为所有产品重量加一个木箱重量。
- `1200×600` 即使带厚度文字也必须识别为小板规格。
- 宁波重量与开单模板必须使用同一宁波运费核心；输出尺寸顺序保持“宽×长×高”。
- 宁波价格必须按“产品名 + 具体规格”精确匹配；手填不存在的规格时保留人工单价并提示人工核对，不得回退到同名第一条价格。
- 宁波重量只能使用已确认的产品重量与厚度资料；缺少权威重量或厚度的产品需要开单人手动填写，未填写前不得生成看似精确的自动运费。

## 七、混凝土仓规则

### 松诺

- 打孔：`7元/㎡`。
- 倒边：`10元/米`，按实际倒边总米数，不取产品平方数。
- 超过 20 个规格的多尺寸费：`10元/㎡`。

### 168

- 打孔：`5元/㎡`。
- 倒边：`5元/米`，按实际倒边总米数，不取产品平方数。
- 干挂孔：`1元/个`。
- 干挂件：`8元/个`。
- 30 种规格以上的多尺寸费：`10元/㎡`。
- 168 清水板、透光板订单总面积 `<5㎡` 时自动加包装费：小板 `1200×600` 为 `100元`；大板 `1200×2400` 或任一单件面积 `≥1.5㎡` 为 `150元`；混合规格取 150 元。
- 总面积 `≥5㎡` 不自动加包装费；旧的统一 200 元规则已取消。
- 开单模板和快速查价中的规则说明必须同步。

## 八、文字报价与界面行为

- 2026-09-19 巡检修复：所有参与当前开单/报价的数字字段须执行已声明的min/step等约束，无效输入提示修正并禁止复制，不用取绝对值、截断或归零掩盖错误；隐藏旧仓和禁用字段不阻断当前业务。KD计算结果本身可以为负，不能按输入校验强行改写。
- 自动按平方计价必须取得有效正面积；未知规格不输出零材料费订单/报价。其它品类可按已确认的手工单片价计价；浙江其它品类全局人工模式需人工明细和材料总额同时齐全，宁波/美利来不使用隐藏旧仓的全局人工值。
- 鎏金、宁波重量按正整数张数核算；1.5等小数须提示修正，不能按1张继续。鎏金公共核心与DB校验同步，界面输出统一“托盘”。
