## 已修复的问题

| 范围 | 原问题 | 本轮处理 |
| --- | --- | --- |
| 公共产品表 | 最新表中的粗纹线石B款遗漏 | 补齐80元/平、2800×1200规格，四个入口共享 |
| 宁波重量 | 多款产品被泛关键词重量覆盖，开单与重量页口径不同 | 按原始Word资料建立非洞石逐产品/规格重量映射；斧开石大小规格分开匹配 |
| 宁波重量目录 | 旧别名仍显示旧尺寸，目录同步可能读到已修改过的条目 | 使用原始资料快照；旧名称作为检索别名，展示最新目录规格 |
| 宁波合装 | 相同产品拆成两行可能重复触发包装费用或改变门槛 | 完全相同产品先合并数量，再计算包装；原货物明细行仍保留 |
| 宁波开单 | 混有缺失重量/无效规格的产品时仍输出部分精确总重 | 停止整单自动重量，提示人工补充，避免漏算 |
| 自动价格 | 改成未知产品仍沿用上一款自动单价 | 清除旧自动价及匹配状态，保留真实手工覆盖，显示核对提示 |
| 文字报价 | 自动补出规格后，本次金额计算仍使用旧规格 | 先同步规格，再读取参数计算 |
| 文字报价 | 用户手改正文被后续表单刷新覆盖 | 手改后保护正文并显示提示；新增恢复自动生成按钮，重置退出手工模式 |
| 税金说明 | 手填税金优先的实际规则在标签上不清楚 | 明确标注手填优先，不变更原有税金计算规则 |
| 美利来包装 | 零或负尺寸可被解析为正常包装费用 | 无效尺寸提示人工确认，不生成看似有效的自动包装费 |
| 整板切割 | 零尺寸/零数量/小数数量/多余字符可能被接受；单空格分隔的多项可能丢失 | 完整解析并校验；负锯缝拒绝计算；计算失败清掉旧结果 |
| 孔心排版 | 零列数、负尺寸、孔位重叠仍可生成图纸；单列不居中 | 校验尺寸、整数孔数和孔距；无效时禁用导出；单列居中 |
| 上墙排版 | 板缝边界无法铺满时显示正常零块结果；无效尺寸仍可导出 | 显示明确错误、清旧结果并禁用导出 |
| 上墙交互 | 重绘移除旧元素后编辑框定位失准；墙名可被当HTML解析 | 重绘前保存位置；墙名按纯文本转义 |
| 报备地址 | 道路名被误判成城市，多省地址直接猜省份 | 采用省市前缀匹配并排除道路名；多省转人工确认 |

原始重量文档已归档到 `平方重量厚度-核对依据.docx`，本轮使用文档读取核对后修正数据，不把名称相近当作充分依据。

- 宁波粗纹线石B款自动带出1200×2800、80元/平；改为未匹配名称后自动价清空，并显示人工核对提示。

## 未擅自修改、需要人工确认的项目

1. **鎏金1200×600小板托盘尺寸**：缺少权威长宽高，继续人工询价，不猜测体积重。
2. **海洞石、洞石拼接历史重量口径**：开单公共洞石通用规则为6.5kg/平、4mm，而重量页海洞石记录7kg/平、4.5mm，洞石拼接记录7.5kg/平、3–6mm。此前明确要求保留洞石资料，因此本轮未改其规格、价格及单品重量规则。使用这两款自动重量前请人工核对；后续确认后应同步两个入口，不能只改一处。
3. **价格表存在但重量资料无法确认的产品**：如花岗岩拼接、平板、马赛克，停止套用泛关键词重量，按页面提示手填。

未修改付款业务规则、税率、已确认价格和无关仓库资料；未删除无关用户文件。
