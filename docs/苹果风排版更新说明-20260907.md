## v2 用户截图修正

- 修补剂：修复通用全宽输入及选项内边距对旧横向卡片的挤压。改为上方规格/价格、下方数量，输入框固定80px；电脑四列、中等窗口两列、手机单列。选中只突出整项，不再出现内外双重边框。
- 侧栏品牌：图标28px，与18px标题同排，版本简写置于下方；详细版本放入悬停提示。桌面品牌区含底部间距64.5px。
- 工具入口：桌面字体14px增至17px、48px按钮高度；白色按钮和浅灰边框分隔各项，当前工具蓝色突出；手机保留横向导航。
- 在独立Chromium实测1280、1440、1920、1024、768、390、320px外窗，包含真实首页侧栏和开单iframe。修补剂各控件未越出卡片，输入宽80px，整页无横向溢出。
- 勾选50g数量2及500g数量1，合计155元；取消50g后数量禁用、合计125元；收起再展开后状态与金额保留。九个导航入口均可切换，无页面脚本错误。
- v2新增2项结构回归，共87项通过；价格和计算JS未修改。v1完整交付ZIP仍保留。

## 使用和恢复

打开本目录 `index.html` 使用完整工作台；若上传GitHub，请上传文件夹内全部内容，不能漏掉 `tools/apple-ui.css` 与 `tools/apple-shell.css`。本轮未操作线上仓库。

后续从 `docs/杰哥工具5.1-开发入口.md` 恢复维护即可，不必依赖长聊天记录。1200×600鎏金托盘尺寸、历史洞石重量口径等仍须人工确认，具体见 `docs/当前版本维护与恢复指南.md`。
